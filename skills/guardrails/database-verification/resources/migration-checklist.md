# Migration Checklist

## Pre-migration

- [ ] Backup previo, verificado
- [ ] Pruebas en snapshot staging
- [ ] Plan de rollback scriptado
- [ ] Ventana de mantenimiento definida

## Durante la migración

- [ ] Verificación de conectividad a BD
- [ ] Validación de permisos requeridos
- [ ] Logs de ejecución habilitados

## Post-migration

- [ ] Verificación de integridad de datos
- [ ] Smoke tests de funcionalidad crítica
- [ ] Confirmación de rollback posible si es necesario
