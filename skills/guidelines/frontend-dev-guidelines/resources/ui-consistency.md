# UI Consistency (Detalles)

## Design Tokens

- Tipografía: tamaños, pesos, familias
- Espaciado: escala consistente (4px, 8px, 16px...)
- Colores: paleta definida, uso semántico
- Componentes: reutilizar librería base

## Reglas

- No hardcodear estilos (usar tokens)
- Componentes base para patrones comunes
- Sistema de diseño documentado
