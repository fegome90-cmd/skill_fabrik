## 🚀 Inicio Rápido

### Instalar Hooks
```bash
node packages/skills-cli/dist/index.js hooks --verbose
```

### Probar Activación de Skills
```bash
node packages/skills-cli/dist/index.js skills check "crear API REST" --v2 --verbose
```
