# Inventario Skills Core

Este directorio concentra los artefactos de auditoría e inventario del proyecto Skills Core.

## Estructura

- `skills-core-inventario.md`: Resumen narrativo del ciclo vigente.
- `skills-core-inventario.json`: Representación estructurada para agentes.
- `hallazgos.json`: Lista de hallazgos con metadatos.
- `acciones.md`: Seguimiento de resoluciones y responsables.
- `metrics-*.json`: Métricas capturadas durante la auditoría.
- `prompts/`: Prompts de Prompt Builder v2 usados en las inspecciones.
- `presprint.md`: Reflexión y handoff del ciclo.

Los artefactos se almacenan por ciclo siguiendo la convención `YYYYQ#`.

## Ciclo activo

- `2025Q4/`: Inventario inicial ejecutado en noviembre 2025.

## Uso

1. Realizar la fase *Clarify* registrando alcance e hipótesis.
2. Ejecutar el plan de auditoría, exportando evidencias aquí.
3. Actualizar los hallazgos y acciones tras cada revisión.
4. Completar el `presprint.md` con lecciones y próximos pasos.
