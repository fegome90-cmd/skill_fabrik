```typescript
// ... 45+ más imports en archivo único
```
**Impacto**: Violación de Single Responsibility, difícil de mantener, testing complejo
**Solución**: Decomposition por dominio (auth, config, metrics, tracing)

### Anti-Patrón 2: TODOs Hardcodeados
```javascript
// ❌ ENCONTRADO EN 10+ ARCHIVOS
plan.approvedBy = 'user'; // TODO: Get from environment
// TODO: Add JSON schema validation
// TODO: Read triggers from config or skill-rules.json
```
**Impacto**: Configuración manual, inconsistencias, deployment inseguro
**Solución**: Environment variables + validation schemas

### Anti-Patrón 3: Backups Acumulados sin Gobernanza
```bash
# ❌ ENCONTRADO
dist.backup.1762011814/
dist.backup.1762021814/
# Múltiples backups sin cleanup strategy
```
**Impacto**: Storage waste, confusion sobre cuál es el estado válido
**Solución**: Automated backup con retención policy
